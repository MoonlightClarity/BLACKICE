# BLACKICE 2.39.98 — isolated release preparation

**Status: candidate source and installer preparation only. Not published, tagged, installed, restarted, or approved for public release.**

This version is based on independently reviewed and source-suite-tested combined commit `154e1e70d0dd1cbaa4bc481d7a233e75bc9d13d5`, which integrates the deadline correction `cc4b97683a46ebedd412c4c17875859d14732810` and the startup receipt-byte change `f815902a7d2ff12f085b111b939fd5c9b70b8d6b`. The complete startup evidence checkpoint `463d24e0841f4c8e08791469b854a2c54e6c5fd7` and its original receipts remain preserved.

Goal deadlines now retain an explicit absolute cutoff and timezone with DST gap/fold rejection, interrupt boundary checks for provider/tool admission, new Goal successors, children and browser delegation, and conservative handling of effects whose external completion is uncertain. Ordinary Goal edits and pause-after-turn preserve the currently admitted turn; a genuinely expired deadline still interrupts it. Invalid local-time errors are displayed in the rendered Goal editor without discarding its draft.

Direct-job startup now reads each saved receipt as bounded raw bytes, decodes JSON once, and computes SHA-256 over the original bytes. Canonical validation, the eight-reader limit, complete history scan, size checks, sorting, exclusive lease, recovery, idempotency and non-replay handling are preserved. A synthetic 281-record comparison suggested a component improvement only; it is **not** evidence that the installed ~234-second whole-startup interval or the user's large real profile improves.

The previous exact combined Windows **source** suite (GitHub Actions run `43728368940`) passed 8,775 of 8,786 assertions, with 11 declared optional skips, zero failures and 780 test files. That run exercised version 2.39.97. The version-adjusted 2.39.98 source and any 2.39.98 installer require their own exact-source/artifact provenance and release checks. These source tests do **not** demonstrate real-provider cancellation, parallel active-child interruption, resolution of in-flight external effects, native asynchronous browser behavior, live-model efficacy or installed-runtime equivalence.

Unfinished Swarm, tab-cleanup, Skills and experimental Directory changes are excluded. Building a candidate uses electron-builder `--publish never`; building is not publishing or installing. The existing `.github/release-request.json` remains the historical completed 2.39.97 publication request. It is intentionally not modified in this preparation branch because changing it would activate the main-branch publication workflow upon later merge. The root release owner must separately decide when to create and review any 2.39.98 publication request after all applicable release gates.
