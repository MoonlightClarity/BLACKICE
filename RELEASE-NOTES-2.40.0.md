# BLACKICE 2.40.0 working candidate

Coherent usability improvements to existing capabilities. Not a published or installer-qualified release.

- Swarm: concurrent project/task sheets, nested folder organization and focused evidence, progress, runtime and history views. Coordination stages remain distinct from execution.
- Knowledge and Skills: nested folders, compact previews and search that reveals matching entries without losing saved collapse state.
- Browser and Cronjobs: nested organization separate from tab ownership and schedule execution.
- Chat: inline folder management and restored narrow navigation. Chat folders themselves remain flat.
- Connections: generic incoming MCP apps are visible alongside branded panels, with accurate compatibility and permission descriptions. This does not add a Mistral provider adapter.
- Mistral Vibe: ACP-first catalog discovery with optional vendor/cache enrichment; catalog limitations are visible in Settings. Live vendor authentication and full catalog parity remain unqualified.
- Recovery: current connection status is distinguished from retained historical delivery records.
- Time management: immediate task-adaptive throughput/thoroughness guidance without another model pass. Explicit Off stays Off; missing old preference adopts On. Behavioral efficacy is not yet established.
- Publisher: manual dispatch only; product versions no longer advance for every internal build attempt.

## Qualification
Focused combined regression and disposable production-HTTP UI results are recorded separately. No full-suite, live provider, package, install/upgrade or public-release claim is made by this note. The release request remains publish:false and deliberately lacks a qualified application fingerprint until exact-source release qualification. Existing identities, profiles, history and data are retained; no live migration was performed here.
