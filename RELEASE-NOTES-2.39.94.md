# BLACKICE 2.39.94

SVG authoring now defaults to professional 2.5D artwork and polished report surfaces, with crisp typography and accurate flat data geometry. A staged checklist asks for concrete observations and repairs. Guidance connects style to construction: silhouette, connected masses, material value ramps, focal color, lighting and deployment size. An optional asset preview sheet shows the unchanged SVG on three backgrounds, at small sizes and in grayscale. Text-layout diagnostics explicitly do not certify design quality. Figures remain inline, with no new tab or toggle.

Directory preserves named sibling dependencies and imports the exact prerequisite result into the next worker. Invalid or ambiguous dependencies retain the original task as one bounded work item rather than silently discarding an edge. Guidance keeps one artifact's design decisions together and keeps brief-only work within its assigned scope.

The spaceship trials exposed these failure modes but were not a controlled comparison. Rendering and dependency regressions verify mechanisms; better future model artwork remains a hypothesis to test. Existing custom SVGs, stored revisions, exports and validation restrictions are unchanged.

Native code-mode preview guidance now explains how to display image data returned alongside text, fixing a tested case where the model rendered an SVG but could not inspect its preview. Structured image outputs remain unchanged.
