# BLACKICE 2.40.11

Candidate source notes, not an installation or publication receipt.

- **Directory** coordinates execution within a task. The Action outline holds actions, dependencies, focus, and observed outcomes. Human edits prevent stale provider work from being attributed to the new action.
- **Planning** can propose and refine those same actions using three modules: Task Decomposition, Calibrated Depth and Action, and Structured Analytic Techniques. Chat shows recorded module activity; enabling Planning is not evidence that a particular module ran.
- **Diagnostics** is separate. It shows retained turn and tool evidence without driving execution. Directory does not require diagnostic capture.
- **Goals** stay in their original conversation. A normal user turn can use conversation history without acquiring a saved Goal's authority, deadline, tools, or budget. Explicit Goal dispatch and Resume remain available in that conversation.
- **Browser** defaults to pages owned by the current task. A fresh task can open a new page in the same browser profile without inheriting an old tab. Explicit recovery of a relevant stopped-task page is still available and does not erase uncertain effects.

Qualification uses local and synthetic fixtures. It does not establish live model performance or application outcomes.
