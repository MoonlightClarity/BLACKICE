# BLACKICE 2.40.12

Status: source candidate. These notes do not establish a local installation or public release.

## Directory
- Ordinary tool receipts do not advance the outline version. Directory validates model writes against the outline snapshot supplied to the model; a newer structural edit still requires re-reading before writing.
- Action admission, effect evidence, and completion remain separate. A tool dispatch alone does not prove an external effect.

## Receipts
- Basic (default) records tool outcomes. Detailed adds context and outline decisions. Maximal preserves an ordered, machine-readable trace for LLM-assisted diagnosis without changing execution behavior.
- Maximal follows the selected turn from context delivery through tool admission, dispatch, result, and final checks. Copy or download the trace under Receipts for that turn. Up to 12,288 events are kept, with gaps marked explicitly. The trace does not contain raw prompts, raw tool arguments or results, credentials, or private reasoning.

Source tests and the native desktop fixture exercise the fix. The original live workload must be retested on the installed candidate.
