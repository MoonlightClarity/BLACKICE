# Summarize a web page

Use when the user wants the substance of a particular page.

## Read the source

1. Reuse the task's matching tab or open the supplied URL in BLACKICE's internal browser.
2. Read the observed tab. Check the final URL and title after redirects.
3. For a long page, use an available text search to find a heading or phrase, then read its surrounding section. A search miss alone does not prove absence.
4. If needed text is behind a link or collapsed section, take a fresh snapshot, use the observed control, and read the resulting content.

Use the browser tool definition attached to the current run for action names and required fields. Use IDs and control references returned by that browser, not an older source example.

## Answer from what you read

Lead with the page's relevant findings. Preserve dates, versions, affected groups, exceptions, table headings, and footnotes that change the meaning. Link the source and label your own inferences.

Example: a release feed links to migration notes. The notes say a CSV endpoint retires June 30 for v1 clients while the Export button remains. Report the date and exact scope; the feed's publication date is not the retirement date.

If the page opens a sign-in wall or stays unavailable, summarize supplied excerpts and identify the missing section. Try an available public counterpart when it can answer the question, clearly naming the substitute. Do not describe inaccessible text as read.
