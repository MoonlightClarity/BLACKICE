# Frame Intelligence Requirements

Use this method when a broad research request risks producing a large descriptive report without resolving the user's decision. Define the uncertainty that matters, the relevant horizon and the observations that can distinguish plausible answers. Continue useful research with stated assumptions when routine context is incomplete.

## Primitives

An intelligence question concerns an actor, capability, intention, event or condition that affects a decision. Information has value when it changes the decision or its implementation. An indicator is an observable event connected to a hypothesis through a stated mechanism. A collection gap is a missing observation, not merely a topic with few sources.

## Procedure

1. State the decision or practical use of the research. Identify what the user can change and when the answer is needed.
2. Specify actors, geography or system boundary, time horizon and key terms. Replace vague labels such as strong, risky or ready with observable distinctions.
3. Write the main question and a small set of subordinate questions that can materially change the answer.
4. Identify plausible answer states and the observations expected under each. Include capability, intent, constraints and implementation where they differ.
5. Rank collection actions by diagnostic value, availability and time cost. Retrieve existing primary evidence before expanding an undirected search.
6. Record what each source can actually establish. Distinguish a public claim, observed behavior and an analyst inference; trace copied reports to their origin.
7. Produce a decision-relevant assessment and the observation that would change it. Update collection priorities when a key uncertainty resolves rather than continuing the original checklist.

## Worked example

The request is to research whether a supplier can support a planned expansion. A general company profile does not answer that question. Define the required capacity, delivery window and acceptable service level. Separate whether the supplier possesses equipment, can staff it, has working capital and has allocated capacity to other customers.

A new facility announcement supports a claim about intended expansion. Commissioning records, delivered output and relevant contract commitments are more directly connected to available capacity. The assessment can recommend a phased order based on current evidence while identifying a specific capacity verification that would support a larger commitment.

## Output and check

Return the decision, primary question, subordinate uncertainties, prioritized collection actions and current assessment. Check that every research branch can change a conclusion, action or confidence level that matters to the user.

## Failure boundary

Do not confuse collecting more material with resolving the requirement. An indicator is conditional, not a guarantee. Avoid inferring intent from capability alone or treating lack of public evidence as proof of absence.
