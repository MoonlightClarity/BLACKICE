# Compare document versions

Compare available versions by meaning and surface material changes with locations in both sources.

**What you need:** Readable text for both named versions; original page or section markers if precise citations matter.

**Approach:** Identify the version pair and align equivalent sections rather than relying on page positions. Separate additions, removals, and replacements; distinguish wording changes from changes in scope, obligations, dates, or amounts.

**Check and recover:** Give a locator for both versions where possible. If an appendix, scan, or one version is unreadable, mark comparisons involving it incomplete and report the confirmed differences separately.
