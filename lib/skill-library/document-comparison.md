# Compare document versions

Use when comparing two drafts, editions, or revisions.

1. Identify both versions from their filenames, dates, or supplied labels.
2. Read the relevant text in each. Align equivalent headings or passages; page numbers can move between versions.
3. Identify additions, removals, and replacements. Separate wording changes from changes to obligations, scope, dates, amounts, or conclusions.
4. Check each material change in both sources and keep a location for each side.

Deliver a table with the topic, old wording or meaning, new wording or meaning, and practical effect. Quote only the short text needed to locate the change.

If a scan, appendix, or one version is unreadable, continue comparing the readable sections and name the missing comparison. A text extraction alone does not establish changes to layout, tracked changes, or comments.

Example: changing “may submit by June 1” to “must submit by June 1” changes the obligation even though the date is unchanged.
