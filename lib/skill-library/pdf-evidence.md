# Read a PDF for evidence

Extract cited claims, tables, or page findings from PDFs and flag scanned, unreadable, or unverified pages.

**What you need:** A PDF attached to this task (relay_files can read its text by page), a supplied page transcript, or a local PDF reader explicitly available in this session. A search result is a path, not an attachment or confirmation that the PDF can be decoded.

**Approach:** Identify the pages that answer the question. Keep printed page labels distinct from file page numbers when the reader exposes both. Compare table headings, units, and footnotes before copying values.

**Check and recover:** Spot-check the exact passage and page for high-use claims. If the reader returns empty text or loses page boundaries, label the affected pages or citations unverified; use a text-enabled copy, the rendered attachment page if image reading is available, or a focused excerpt.
