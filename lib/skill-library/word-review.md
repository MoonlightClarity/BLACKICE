# Review a Word document

Use to review or revise Word prose and tables.

## Read the relevant text

1. For a local DOCX, use the attached local-file reader with one actual path. Find an unknown path first, then read the selected result.
2. For an attachment, use its returned attachment ID with the attachment reader.
3. Read the relevant paragraphs and tables. Use the current reader's search, range, and continuation fields for additional text. A reader's cursor names can differ from another reader's.
4. Check nearby sections or tables that change the passage's meaning.

## Review or edit

Give located comments or complete replacement text when that is the requested result. For an edited Word file, use an available compatible editor, save the output, and inspect the resulting document. Text extraction alone does not modify a DOCX or verify layout, comments, or tracked changes.

Confirm names, dates, amounts, and qualifications against the source. Example: prose says “next week” but a milestone table says “Friday, May 14.” Resolve the discrepancy from context or flag the conflicting dates rather than silently choosing one.

If the file changed during reading, reread the path. For an unsupported format or unreadable section, use another available reader or supplied copy, and finish the readable parts. Report suggested text as a suggestion and saved edits as saved edits.

Build calls from the attached tool schema. Source files and older examples may describe another version.
