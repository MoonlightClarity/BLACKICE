# Review a Word document

Review a Word draft and give located comments or a revised text version without implying formatting was preserved.

**What you need:** A DOCX attached to this task (relay_files can read its paragraphs and tables), supplied text, or a local DOCX reader explicitly available in this session. A discovered path is not a task attachment. Text extraction is not Word editing and does not guarantee access to layout, comments, or revisions.

**Approach:** Work by section. Distinguish suggested text edits from questions and substantive changes. When the user needs an edit, present the replacement language in context, preserving names, numbers, terms, and the writer’s voice.

**Check and recover:** Check every rewrite against its source paragraph and note sections you could not read. If the available reader only extracts text, return marked-up prose or an edit list and state that no Word file was modified.
