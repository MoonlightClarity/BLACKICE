# Draft for a specific audience

Write a useful message or short document for its intended reader without sending it.

**What you need:** Audience and purpose; a sample or style cues if matching an established voice matters.

**Approach:** Lead with what the recipient needs to know or do. Include only context that helps them act. Keep consequential promises, dates, prices, and decisions aligned with the facts supplied. Use placeholders only when a missing fact belongs in the draft.

**Check and recover:** Read as the recipient: is the requested action clear, and is anything implied that the user did not intend? Deliver copy-ready text and identify open placeholders separately. A draft is not a sent message.
