# Draft for a specific audience

Use when writing a message, paragraph, or short document for a named reader or purpose.

1. Identify the reader, the point they need to understand, and any action they should take. Use supplied context and choose a reasonable tone when the user leaves it open.
2. Lead with that point or action. Put the supporting facts beside it; remove background that does not help the reader.
3. Keep names, dates, amounts, and promises consistent with the supplied facts. Use a clear placeholder only for a missing fact that must appear in the draft.
4. Read the draft as its recipient: can they tell what happened, what is being asked, and when it matters?

Return complete, copy-ready text. List unresolved placeholders separately so they are easy to replace. If the user also asked to send it, continue through the available sending tool and check the result; a saved draft alone does not fulfill that action.

Example: for a delayed delivery, state the new date, the reason the reader needs, and the requested response. Avoid a long account of internal work.
