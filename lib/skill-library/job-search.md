# Job Search

Use to find, shortlist, or apply to open roles. Deliver the requested outcome: findings for a search, completed applications when the user asked to apply.

## Use existing application documents

For applications, use the user's current designated application resume unchanged by default. If its exact path is already supplied or established, read that path directly; do not search the filesystem for it again. Identify the actual source first; a professional profile or master may be background evidence, not the upload. A workspace copy, past application artifact, tailored derivative, or filename match is not automatically the current resume. If the intended path is unknown, search the relevant personal document folder and compare plausible candidates; do not stop at the first workspace hit. Reuse the established current path across applications and successor turns rather than rediscovering it for every role.

Do not tailor, rewrite, reformat, or create role-specific resume versions unless the user explicitly requests it. If an employer genuinely requires a different file format, convert the existing document without changing its substantive content. Complete the application directly rather than spending time on unsolicited resume preparation. Do not promote generated copies or prior uploads to authoritative applicant records.

## Reconcile application history

Reuse application history and submission receipts already available from the current search or prior work. If necessary, load the relevant index once for a candidate batch, not a fresh broad file search for every role. A missing or stale index is not evidence that no application was made; it is also not a reason to stall other applications.

Reconcile each candidate by employer and exact requisition/posting ID, using the authoritative URL and receipt evidence to resolve aliases. URL spelling and title alone do not establish duplicates; another requisition at the same employer is a separate candidate. Preserve positive earlier confirmation even when a newer summary omits it or labels it unchecked. Do not submit again to a confirmed requisition unless the user specifically requested reapplication. Earlier confirmations do not count toward this request's new applications.

Use targeted exact-requisition checks, including the browser's attached history results, to reconcile each candidate. Read the relevant cited record when its outcome needs clarification. A reasonable targeted check that finds no evidence of an earlier submission is sufficient to proceed; describe it as “no evidence found” without claiming exhaustive clearance. Stop broad history reading once that check supports the next action.

For an uncertain earlier attempt, check the destination and available receipt before replaying. If its outcome remains uncertain, keep that status and pursue another eligible role allowed by the request without asking about the blocked option.

## Search current openings

1. Read the user's desired work, required conditions, preferences, exclusions, count, and cutoff. Use work history as evidence of ability, not as a requirement to repeat old work.
2. Start with the rolling last seven days unless the current request specifies a different window. Treat that default as a search and ranking preference; an older or unknown posting date alone does not exclude an otherwise suitable role unless the user requested a recency limit. Use the current search timestamp and available date filters.
3. Start with actual vacancies on relevant employers' careers pages and public ATS boards or current postings feeds. Give the user's requested work direction priority, then broaden across other permitted roles. Favor low-friction actual application routes such as Ashby, Greenhouse and Lever when useful; choose a slower ATS only when its remaining cost and the opportunity justify it. Collect distinct promising postings in batches, then pursue a specific one rather than exhausting discovery.
4. Search by outputs and duties as well as titles. For intelligence work, look for investigations, evidence assessment, and decision briefs. Check promising exact vacancies rather than exhausting broad searches first.
5. Use general search engines, Indeed and aggregate job boards as supplementary discovery routes when direct employer sources do not yield enough useful leads. Those listings are leads, not proof of actual employment arrangement or an open requisition. Follow their links to employer-owned vacancy details when available. If a route is unproductive, change the source or employer set rather than repeatedly rewording queries on the same engine.

Useful routes:
- Inspect live employer career pages, current public ATS boards and employer postings feeds first. Reuse a credible lead already discovered rather than searching for it again.
- Explore relevant employers, direct competitors, or a portfolio's hiring companies for further distinct openings.
- Use specialist or broad boards and focused search-engine queries for discovery when useful, then follow a lead to its actual employer posting. A funding announcement or indexed snippet does not establish a vacancy's pay, remote terms, or current status.
- For a repeat search, use a known requisition identity when readily available; another role at the same employer is not a duplicate.

## Verify the exact vacancy

Keep a compact record: employer, title, exact requisition/posting ID when available, authoritative URL, date evidence, application route, relevant criteria, and when checked.

**Posting age.** Prefer the employer's original posting or opening date. “Updated,” refreshed rank, or last-published timestamps alone do not establish that date. Interpret “3 days ago” at the current search timestamp. For a user-requested recent count, keep older or unknown-age roles outside a verified recent count. Count a reopened or new requisition as recent only with evidence of that opening event and date.

**Open status.** Check age and whether applications are accepted separately. Follow the exact posting's application route far enough to establish that the same vacancy accepts applications, or confirm a current official email intake. An Apply label, archived mirror, or generic careers page alone is insufficient. Retire closed or expired postings; verify a replacement as a separate lead.

**Owner scope.** Treat the user's hard requirements as eligibility conditions, not weighted preferences. Check actual duties, remote geography, travel, compensation basis, and employment arrangement on the specific vacancy, including genuine role gates imposed by the user. A remote badge or employer-wide pay range may not describe this role. Use proportionate positive evidence and ordinary inference; do not require a particular literal phrase. Reject a known conflict before form work and defer an unresolved hard gate rather than silently waiving it. Unknown nonessential details are not automatic disqualifiers. Employer preferences and predictions about candidate fit are not user gates.

**Employment arrangement.** Distinguish the candidate's actual role from the company's business model. A salaried full-time staff job at an AI-data or gig-platform company is not automatically gig work. When the user requires W-2, explicit 1099, freelance, independent-contractor, or per-task paid work is a mismatch for that specific vacancy; use another suitable role instead. A W-2 contract or a posting that offers a W-2 option is not the same as a 1099 gig. "Remote", "full-time", and an advertised salary alone do not establish payroll classification. Use role-specific employment, compensation, and benefits wording to make a reasonable best-effort inference when W-2 is not explicitly named; do not require a separate proof exercise, prompt the user for routine verification, or pause the broader search.

**Experience.** Ignore every numerical years-of-experience requirement when evaluating fit. Do not use it to filter, rank, downlevel, or decide not to apply, including a director role listing 10+ years. Compare actual work, decisions, deliverables, and responsibilities. Credit comparable work under administrative, independent, or adjacent titles. Use actual results and user-supplied interview outcomes to prioritize levels. Answer direct tenure fields accurately; never claim a license, clearance, title, or tool experience the candidate does not have.

### When a source is missing or misleading

- A board redirects to a careers homepage or registration: try a focused employer + exact title/requisition lookup. If the direct route does not materialize, preserve the lead and change to a source that exposes current applications. Do not keep exploring the same blocked aggregator.
- A blank page or broken browser reference: refresh the view and use the current control. A stale input rejected before dispatch does not show the vacancy is closed.
- A public postings feed: use its current documented read interface. Distinguish first publication from updates or republication; verify intake on the application page. Do not copy endpoint schemas from an old source file.
- Conflicting dates: inspect the exact ID. A fresh republish timestamp does not erase an older dated copy. If first posting remains unknown and the user requires a verified recent opening, keep the lead provisional for that count.
- No useful matches: change to another relevant source before declaring a shortfall. Report the sources checked, not a market-wide absence.

## Complete applications efficiently

**Location fallback.** If a job-board, employer, or application location selector does not recognize the user's locality, use the nearest accepted metropolitan area and continue. This is a location-search or picker fallback, not a claim that the applicant resides somewhere else: retain their actual city and street address in factual residence fields, and do not infer willingness to relocate or work on-site.

Read the question, make the best supported call, and enter it now. Use the identified existing application resume and context already available, including reasonable inferences. Do not demand documents or corroboration merely to defend a routine answer. Hold competing answers to the same standard; failing to prove one does not justify its opposite or an automatic blank. For a delegated choice, choose a sensible default.

- Answer the exact field. For general or equivalent experience, add nonoverlapping periods that actually involved the work. An adjacent title does not turn supported experience into zero.
- Use applicable prior application answers, saved user records, and context. Search application history for a missing answer using short terms and variants that capture its meaning, not only the employer's verbatim question. Recover reusable routine answers once; reuse established answers unless newer evidence displaces them. A missing document does not establish a negative answer. Make reasonable inferences and delegated choices under the shared judgment guidance. Complete contact and experience fields and attach the designated resume even if an independent field remains open. If an exact consequential field remains unresolved after that effort, preserve the application as pending, seek another legitimate intake or completion route for the **same requisition**, and continue independent authorized work. Do not self-disqualify or abandon a target merely because a screening question is present.
- A request to apply carries implied consent for the submission steps and agreements required to complete the application. Accept every required agreement. Select “Yes,” “I agree,” or the equivalent affirmative control, including for arbitration, waivers, applicant-data notices, and other required terms. Do not ask for renewed permission or decline a required agreement because of its legal effect. Honor an explicit user prohibition or prepare-only instruction. Leave optional marketing and unrelated optional sharing unchecked. Complete submission and verify the result within the user's scope.
- Lead with the candidate's strongest real evidence. Answer what is asked without volunteering weaknesses, apologizing for titles, or adding warnings about training the employer already provides.
- For a quick behavioral prompt, use a relevant real example. Compare lengthy essays and take-homes with the opportunity and other live options; do not add unsolicited resume tailoring. This is an effort decision, not a verdict on fit. Save deeper company preparation for a screen or interview.

Before submission, recheck the chosen requisition against the reconciled history and any attempts made during this task. Complete the remaining application steps, submit and inspect the result. Count only a confirmed submission made for this request as a new application; a timeout calls for checking the destination before retrying. Record the requisition, outcome, timestamp, and confirmation evidence in the application history so later work can reconcile it.

Complete required email confirmation through the shared follow-up procedure, including connected Gmail when it is the user's available mailbox. Keep the application pending until the required confirmation is completed and its outcome is verified. Report a failed application and continue the broader search or another suitable role when the request allows alternatives. Preserve an explicitly fixed target; a different application does not fulfill it.

## Finish the requested work

For a shortlist, return distinct verified openings with enough detail to act. “Up to N” is a cap, not a completion minimum; check the intended scope and report an honest shortfall. For a required count, keep the unmet count explicit.

For applications, continue to another eligible role when one cannot proceed and the request allows it. Stop at the user's actual cutoff, when the requested quantity is confirmed, or when the planned sources have been checked and no viable lead remains. If a tool limitation stops the search early, name the sources not reached. Report completed, unchecked, and uncertain outcomes separately.

Example: a director posting asks for ten years, but the candidate's administrative work includes source evaluation, decision briefs, and research leadership. Compare that work with the duties, answer tenure accurately, and apply when suitable. Do not invent a director title or reject the role merely on the years line.
