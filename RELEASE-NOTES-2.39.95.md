# BLACKICE 2.39.95 candidate

This source candidate removes the uncertain-actions review panel from Chat. Saved uncertain-effect receipts and their history remain intact.

Browser and workspace validation failures are classified as not dispatched only at host boundaries that prove execution did not begin. The same validation error after dispatch remains unknown. Goals can inspect and reconcile exact receipts during their own active turn. A deliberate model risk judgment may authorize one retry of an unknown receipt; it is not proof of absence. The authorization is persisted before dispatch, cannot be renewed on that receipt, does not transfer to another run, and never automatically replays an action. Other work can continue while uncertainty remains.

Startup now emits bounded numeric phase diagnostics, including lease, enumeration, full receipt scanning, validation, indexing, sorting and recovery. Eight bounded readers replace four, retaining every validation, hash check, lease and recovery rule. On one copied 64,351-receipt, 1,246,950,056-byte history, four/eight/eight/four read-only scan trials took 37.181/29.739/28.182/32.120 seconds with identical receipt-state hashes. Cache was not flushed and other host work was uncontrolled. These measurements exclude lease acquisition, recovery writes and whole-app startup. They do not explain or claim to fix the earlier 325.7-second startup.

The initial focused source checks passed 299 tests. Follow-up driver checks passed 142 tests, including first-input refusal, partial key and pointer sequences, lost replies, focus preparation and restored navigation. A host-proven unsent press no longer causes a cleanup release event. An additional autonomy/worker/llama.cpp set passed 47 tests; its HTTP integration test was blocked by the local test environment's EACCES loopback restriction. Full Windows source and installer verification remain separate release gates. This note does not claim this candidate is installed or published.
