# BLACKICE 2.40.17

Status: source candidate. These notes do not establish a local installation or public release.

- Directory settles an unsuccessful attempt when the host proves the operation never dispatched. Entering the tool handler is not the same as sending input to the page.
- A stale browser reference during read-only preflight is marked not dispatched. The original call is not retried automatically. A new, explicitly chosen current reference still goes through ordinary validation.
- If the browser could have sent input, or the host cannot prove otherwise, the attempt remains unknown. A stale-reference error code alone and input-only flags do not clear that uncertainty.
- Maximal receipts distinguish entering the handler from proven non-dispatch.
