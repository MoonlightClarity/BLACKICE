# BLACKICE 2.40.6

Candidate source notes, not a publication or installation receipt.

## Current changes

- Remove the separate To-do and My workflows UI, routes and services. Existing files are left on disk, not automatically imported or executed. Cronjobs retain their current saved-workflow editor.
- Organize immutable release Skills and browser tabs in nested folders. Browser folder rendering is app-owned rather than an auxiliary extension DOM protocol. Chronological Cron listings and concise automatic chat titles preserve manual titles.
- Render validated static SVG content inline in Chat with source disclosure and Copy. Unsafe, incomplete or malformed content remains escaped; rendering does not enable SVG scripts or external resources.
- Replace Directory context controls with retained-event Activity. Retired Directory execution/history cannot be resumed as ordinary work. Remove automatic learning and mutable memory services while preserving current explicit Skills/history retrieval and owner-edited identity.
- Use current native tool contracts and reject incompatible saved catalogs rather than migrating or adapting them. An affected conversation requires a fresh session; saved records remain on disk. File search remains the narrow relay_find_files callable in fresh sessions.
- Preserve explicit canonical work-item ownership when delegating with Planning Off. Restore saved checkpoint discovery through an explicit bounded, revision/hash-pinned historical read, without ambient prompt injection or treating that read as acknowledgement of current intent.
- Preserve an attached native sign-in tool on unchanged continuation, without relaxing browser availability, authorization or catalog fingerprints. Compaction now waits for conversation archive persistence before reporting success; a failed archive save reports failure without replaying the native effect.
