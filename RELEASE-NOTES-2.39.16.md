# BLACKICE 2.39.16

## Planning in the user's interests

- Compare proceeding, asking, and deferring through a shared, deterministic expected-user-cost calculation. Include concrete consequence probability and severity, delay, interruption, and lost opportunity on the same documented scale and time horizon.
- Require numerical justification for consequential escalation in new planning checkpoints. Recompute from raw inputs and reject a selected option that contradicts the result; changed evidence or assumptions require a fresh calculation.
- Preserve explicit uncertainty and show sensitivity and clarification break-even values. Tiny possible risks do not receive an uncertainty multiplier or a category-based veto. Actual sourced user constraints remain separate from risk estimates.
- Distinguish candid progress reports to the user from counterparty-facing material. Present relevant supported strengths and answer the actual question without adding unsolicited experience-gap disclaimers or internal form-filling notes. A required field label does not by itself justify interrupting the user.

## Direct external planning

- Let an authenticated external agent create a standalone shared plan through the existing planning connection, without starting a BLACKICE model or run.
- Persist quantitative assessments, user-agency checkpoints, revisions, and actor history in the canonical plan store. Plans remain discoverable after reopening the application.
- Expose the same calculation and guidance to native and external agents. Preserve revision conflicts, recursive edits, existing saved plans, cached tool schemas, and Planning Off behavior.

## Verification

- Add regression coverage for low-probability correctable consequences, useful and unhelpful questions, personal backup decisions, opportunity cost, unknown estimates, deterministic ranking, and external plan creation/readback/revision.
- Bind Windows source-test evidence and the public installer checks to the exact release candidate.
