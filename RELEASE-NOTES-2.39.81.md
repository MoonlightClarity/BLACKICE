# BLACKICE 2.39.81

## Opt-in reasoning with preserved choices
- Unspecified selectable Planning modules and Directory start Off. Explicit current Boolean and saved module choices remain unchanged.
- Selected modules and optional delegation remain available when expected benefit justifies time, tokens, and coordination. No module capability was pruned.
- README and the repository trade-offs guide distinguish selective usefulness from default-on consistency. Earlier small benchmarks do not establish universal improvements on this version.

## Live Directory direction delivery
- Parent directions can reach the currently active Directory phase without treating its child session as the resumable parent conversation.
- Queued, delivered, undelivered, and uncertain states are represented separately. A queued direction is no longer displayed as delivered.
- Interrupted in-flight delivery remains uncertain and is not automatically replayed. Identity checks protect replacement phases and stopped work.

## Verification and limits
- Production-engine synthetic tests cover direct default-Off execution and preservation of explicit current choices through failure, reopen, Retry, and Continue. Feature fixtures explicitly select the modules they exercise.
- Deterministic direction routing, race, interruption, and rendered UI tests cover the delivery protocol. Live-provider delivery efficacy is not claimed.
- This release preserves the recovery warning and startup indexing changes from 2.39.80. Exact combined source tests, public installer checks, and local runtime checks remain separate gates.
