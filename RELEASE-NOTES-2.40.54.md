# BLACKICE 2.40.54

Windows test candidate.

- After a stale input that did not reach the page, the browser can briefly wait for navigation to settle and return a current snapshot. It never retries the click by itself.
- Directory no longer accepts a claim that a search reached its limit unless successful reads cover the declared sources. A real host deadline remains separate.
- Models no longer offers the standalone external catalog. Accounts, Local models, Add API, and model discovery for a saved connection remain.
- Deleting an API removes it from model choices. An affected chat or default explains that the connection was removed without showing the internal ID or switching providers on its own.
- Anti-Overalignment and Anti-Completion Bias cover separate failures. Verify a Working Slice and Expand a Catalog are available as optional skills.

A controlled public browser test verified the recovery step, not a completed job application.
