# Cobalt Studio: help-centre migration proposal

Prepared by Cobalt Studio for the pilot evaluation.

Our managed editor stores articles in its own document format. A one-time Markdown import is included. The import preserves basic formatting, but custom callouts and some cross-article links need manual review.

The pilot includes importing a sample, configuring the help-centre theme and giving the team an editor walkthrough. After migration, routine editing takes place in the managed editor. Export is available as Markdown, with a separate links file.

Our team operates the publishing service and its updates. Your team maintains the articles and checks exported links if it later moves platforms. Useful review topics are the manual cleanup effort, the change to the authoring workflow and the export format.
