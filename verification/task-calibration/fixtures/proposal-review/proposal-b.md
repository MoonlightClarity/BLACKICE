# Brookline Tools: help-centre migration proposal

Prepared by Brookline Tools for the pilot evaluation.

Our documentation generator keeps the existing Markdown files in your repository. It generates a static help centre and can be deployed with your current build process. Search runs against an index produced at build time.

The pilot requires choosing a theme, connecting the build and reviewing navigation. Standard Markdown needs no conversion. Existing custom callouts need a small rendering extension. Your team owns the build configuration and applies generator updates.

We can provide a sample project for the pilot. The first review should clarify who will maintain the rendering extension, how the build fits the existing release process and whether the search experience meets your needs. No migration workshop is included in this proposal.
