# Alder Works: help-centre migration proposal

Prepared by Alder Works for the pilot evaluation.

Our hosted service imports Markdown through a repository connector. Import preserves headings and links; custom callout syntax needs a conversion rule. We offer a staging site for checking converted pages. The customer's team maintains the source repository and approves publication.

Setup includes configuring the connector, defining the callout rule and checking a representative batch of articles. Our team supplies an initial configuration session. The customer maintains the conversion rule when its source conventions change.

## Our recommended evaluation procedure

For a complete assessment, our preferred process reserves a full working day. We recommend ninety minutes for the product overview, two hours for an integration workshop, ninety minutes for a migration walkthrough, ninety minutes for a section-by-section review of the feature notes, and thirty minutes for a shortlist discussion. We recommend completing all five stages before a supplier is shortlisted.

The repository connector and conversion-rule maintenance are the most useful topics to cover with your technical reviewer.
