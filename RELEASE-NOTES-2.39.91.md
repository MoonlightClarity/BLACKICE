# BLACKICE 2.39.91

SVG authoring now includes concrete drawing guidance: text measurement and wrapping, spacing, connector routing and clearance, paint order, restrained BLACKICE colors, and narrow-display legibility. Small supported SVG fragments teach shared dependence, missing coverage and long-label annotations without imposing whole-diagram templates.

The guide discourages decorative text slides, automatic all-caps labels and oversized title bands. Examples use quieter headings. Visuals remain inline and available without a toggle; there is no dedicated Visuals tab. Existing saved artifacts and exact exports are unchanged.

The release preserves the current Git author-attribution checks. Rendering and compatibility are tested; the appearance of future model-generated drawings still needs assessment in real use.
