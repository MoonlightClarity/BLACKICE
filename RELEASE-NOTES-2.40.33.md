# BLACKICE 2.40.33

Windows test candidate.

- Chat shows an alarm when a tool or skill load fails. The alarm separates what the tool returned from possible causes, groups repeated failures, and does not edit or retry anything.
- Archiving or moving a chat to Trash permanently removes its diagnostic Receipts. Messages and files remain available according to the chat's state. Restoring the chat does not restore removed Receipts. Installation does not purge already archived chats.
- The browser tool explains how to upload an existing local file directly without registering it as a Chat attachment first.
