# BLACKICE 2.33.7: connected planning, swarms and schedules

Planning, saved swarms and scheduled work now share the same navigation. Swarms and Schedules are directly reachable from the desktop header and compact workspace menu.

## Navigate and keep your place

- Move between Planning, Swarms and Schedules from a shared navigation strip with a clearly marked current area.
- Return to the plan or saved swarm you selected. Explicit links to a particular plan still open that plan.
- Distinguish saved swarms from the quick swarm builder, with clearer worker-run and task-plan actions.
- Keep unsaved schedule forms within the current app session when moving between areas. Resume or discard the draft explicitly; saving clears only the draft that was saved.

## Organize plans and scheduled work

- Planning identifies its saved chat plans and keeps the plan lifecycle controls for archive, trash and restore.
- Remove a named planning group from beside its name while keeping its plans in Ungrouped. Keyboard navigation and focus remain stable.
- Jump directly to saved schedules or job history, see which schedule scopes the history, and clear that scope.
- Use consistent schedule-manager and workflow-scheduling labels, with clear return actions.

The layouts support narrow windows, and navigation itself does not submit tasks or start workers. Schedule drafts are retained for the current UI session; they are not saved across an app restart.

Vendored method catalog files also retain their exact pinned bytes in Windows checkouts, preventing line-ending conversion from invalidating their integrity checks.

Release evidence is bound to the exact source commit, application fingerprint and installer checksum. The release includes the full Windows test receipt and installer verification produced for this version.
