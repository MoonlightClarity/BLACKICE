# BLACKICE 2.40.59

Local Windows candidate, separate from the 2.40.57 GitHub release.

- A stop or diagnosis-only follow-up does not execute the old Directory plan. The outline and receipts remain available, and an explicit request to continue resumes normal execution.
- Adds the Steerability skill, with examples of stopping work, reporting known effects, and resuming only when asked.
- Bare connectivity checks on a local model no longer load execution tools or activate Directory.
