# BLACKICE 2.40.16

Status: source candidate. These notes do not establish a local installation or public release.

- Directory plans replace pending actions, not recorded work. New actions can depend on recorded action IDs without copying their text or evidence.
- If a plan would rewrite recorded work, Directory rejects the edit and gives the agent a bounded chance to add the next steps. It does not treat a completed discovery step as proof that the larger task succeeded just because the extension failed.
- Maximal receipts distinguish a plan that needs repair from ordinary pending work. The rest of the task retains its original scope.
